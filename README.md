# Snake Royale

A real-time multiplayer Snake game built with Python and Pygame using a TCP client-server architecture.

## Features

- Real-time multiplayer gameplay
- TCP socket communication
- Custom JSON-based networking protocol
- Multithreaded server
- Server-authoritative game state
- Player challenges and matchmaking
- Spectator mode
- In-game chat
- Snake customization
- Obstacles, food, health, and collision mechanics

## Tech Stack

- Python
- Pygame
- TCP/IP sockets
- Multithreading
- JSON
